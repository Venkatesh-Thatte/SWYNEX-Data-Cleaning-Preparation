# Excel Data Cleaning & Validation Assignment

This project demonstrates practical Excel data-cleaning and data-validation skills using a sales transaction dataset.

## Objective
To clean a raw sales dataset and prepare it for reliable analysis by identifying and correcting data-quality issues.

## Tasks Performed
- Identified and removed duplicate Order IDs
- Handled missing Customer Names
- Handled missing Quantity values
- Handled missing City values
- Standardized inconsistent City names
- Standardized Product names
- Standardized Payment Mode values
- Corrected invalid Quantity values
- Corrected invalid Unit Price values
- Created a Cleaning Log to document corrections
- Performed validation checks after cleaning

## Excel Skills Used
- Data Cleaning
- Data Validation
- Duplicate Detection
- Missing Value Handling
- Data Standardization
- Excel Functions
- Sorting and Filtering
- Data Quality Checks

## Workbook Structure
- Raw_Data – Original dataset
- Cleaned_Data – Final cleaned dataset
- Cleaning_Log – Record of identified issues and corrective actions
- Validation – Data-quality validation results

## Outcome
The cleaned dataset is ready for further analysis and reporting, with duplicate, missing, inconsistent, and invalid data issues addressed and validated.
